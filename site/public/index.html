Trifft eines davon auf Sie zu?

Alter Server
Der reguläre Support für Windows Server 2016 endet am 12. Januar 2027. Wenn Ihr Server noch damit läuft, ist das ein Anlass, den Ersatz zu planen.
Ungetestetes Backup
Neun von zehn Schweizer KMU erstellen Backups. Nur jedes vierte testet, ob sich die Daten im Ernstfall wiederherstellen lassen (Studie «KMU Cybersicherheit 2026»). Auf der Box stellen wir jeden Monat zur Probe Daten wieder her. Das Ergebnis steht in Ihrem Monatsbericht, als Nachweis für Revision und Versicherung.
Dateien bei US-Anbietern
US-Behörden können US-Anbieter zur Herausgabe von Daten verpflichten, auch wenn der Server in der Schweiz steht (CLOUD Act). Mandanten-, Patienten- und Projektdateien auf der Box liegen in Ihren eigenen Räumen. Für E-Mails ändert die Box daran nichts.

Wer was übernimmt

Ein fester Monatspreis deckt Hardware, Software, lokales Backup und Betrieb. Der Wartungsvertrag für die ersetzten Geräte entfällt.

Die Box
Ein geschlossener Schrank. Er braucht eine normale Steckdose und einen Netzwerkanschluss, aber keinen Serverraum. Eine eingebaute Notstromversorgung überbrückt kurze Stromausfälle.
Strom und Lautstärke
Beides ist noch nicht gemessen. Ausgelegt ist die Box mit drei Servern auf rund 150 Watt, das wären etwa CHF 30 Strom im Monat. Mit einem Server ist es etwa ein Drittel davon.
Wir
Updates und der Ersatz defekter Hardware sind unsere Sache. Ein vorinstallierter Ersatzserver kommt per Kurier aus St. Gallen. Die Box wird rund um die Uhr automatisch überwacht, und jeden Monat erhalten Sie einen Bericht.
Sie
Im Portal der Box nehmen Sie Mitarbeitende auf, vergeben Zugriffe auf Ordner, holen eine gelöschte Datei zurück und sperren die Zugriffe, wenn jemand austritt. Das geht ohne Anruf bei uns, und jede Änderung wird mit Person und Zeitpunkt protokolliert.
Ihr IT-Partner
Er betreut weiterhin Arbeitsplätze, Drucker und Telefonie. Diese Leistungen sind im Monatspreis nicht enthalten.

Die Umstellung in drei Schritten

  1. Analyse Wir kommen für eine Stunde zu Ihnen, kostenlos. Danach wissen Sie, welches Paket passt.
  2. Einbau und Umzug Wir liefern die Box fertig eingerichtet und kopieren Ihre Dateien darauf, geplant an einem Wochenende. Beim bisherigen Anbieter sollen die Dateien bleiben, bis Sie den Umzug geprüft haben.
  3. Betrieb Die ersten zwei Wochen begleiten wir Sie. Danach regeln Sie die Zugriffe im Portal, den Betrieb der Box übernehmen wir.
